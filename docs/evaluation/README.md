# 평가 지표와 결과 해석

[메인](../../README.md) · [English](README_EN.md)

## 왜 여러 지표를 쓰는가

매장·상품군마다 판매 규모가 다르고, 작은 평균 오차가 드문 대형 실패나 지속적인 과소예측을 가릴 수 있습니다. 따라서 **판매량 단위의 평균 오차, 큰 오차, 전체 물량 대비 오차, 예측 방향**을 함께 봅니다. 아래에서 `y`는 실제 판매량, `ŷ`는 예측 판매량, `n`은 평가 행 수입니다. 계산 전 음수 예측은 0으로 보정합니다.

| 지표 | 계산 원리 | 값이 답하는 질문 | 해석 시 주의 |
|---|---|---|---|
| MAE | `평균(|y−ŷ|)` | 평균적으로 몇 개를 틀렸는가? | 판매량 단위이며 큰 오차를 제곱하지 않음 |
| MSE | `평균((y−ŷ)²)` | 큰 실패를 얼마나 강하게 감지하는가? | 큰 오차에 **민감**하고 단위가 판매량의 제곱; 현재 최종 결과 표에는 별도 저장하지 않음 |
| RMSE | `√MSE` | 큰 실패를 강조하면서 몇 개 단위로 볼 수 있는가? | 드문 큰 오차가 수치를 크게 움직일 수 있음 |
| RMSLE | `√평균((log(1+y)−log(1+ŷ))²)` | 판매 규모가 다른 사례에서 로그 차이는 어떤가? | 0 판매도 계산 가능하지만 MAE처럼 판매량 단위로 읽지 않음 |
| WAPE | `Σ|y−ŷ| / Σy × 100` | 전체 실제 판매량 대비 총 절대오차는 몇 %인가? | `Σy=0`이면 정의되지 않음; 규모가 큰 판매의 오차가 합계에 크게 기여 |
| Bias | `Σ(ŷ−y) / Σy × 100` | 전체적으로 과대 또는 과소예측하는가? | `+`는 과대, `−`는 과소; 서로 다른 방향의 오차가 상쇄될 수 있음 |

MAE는 운영자가 이해하기 쉬운 평균적인 수량 오차, RMSE는 드문 큰 실패, WAPE는 전체 물량 대비 오류, Bias는 발주·배분에서 중요한 **오차의 방향**을 보여줍니다. RMSLE는 규모 차이에 대한 추가 관점입니다. 0 판매 행이 있어 일반 MAPE의 행별 분모가 불안정하므로 WAPE를 사용하지만, WAPE도 **평가 집합의 전체 실제 판매량이 0이면 계산할 수 없습니다.**

## 학습 손실과 최종 평가는 다르다

현재 전체 이력 LightGBM은 L2 `regression`, CatBoost는 `RMSE`로 나무를 학습합니다. N-HiTS·TCN·TFT는 MSE 손실을 사용하고 내부 검증 MSE를 학습 중 모니터링합니다. 내부 DL 손실은 모델 내부 스케일과 7일 검증 구간에서 계산되므로, 최종 공통 Test의 WAPE나 MAE와 같은 값이 아닙니다. **같은 정답·예측 행**에 최종 지표를 다시 계산해야 모델을 비교할 수 있습니다.

## 최근 제출한 공통 Test 비교

아래 WAPE는 사용자가 대화에서 제출한 최근 결과를 정리한 **문서 초안 수치**입니다. Test 기준일 2017-08-02~08의 매장·상품군·기준일·horizon을 맞춘 비교이며, 실행 산출물과 정확한 설정이 함께 보관되면 최종 결과로 확정할 예정입니다.

| 모델 | 일별 WAPE ↓ | 7일 합계 WAPE ↓ | 현재 해석 |
|---|---:|---:|---|
| LightGBM | **14.88%** | **10.70%** | 제출 결과에서 두 범위 모두 가장 낮음 |
| CatBoost | 16.77% | 11.96% | 같은 표형 입력의 비교 모델 |
| N-HiTS | 20.87% | 14.20% | DL 세 모델 중 가장 낮은 WAPE |
| TFT | 25.21% | 18.58% | 더 긴 학습이 항상 나은 최종 성능을 뜻하지 않음 |
| TCN | 28.59% | 22.08% | 현재 설정에서 주간 합계 오차도 큼 |

일별 평가는 각 `t+h` 판매량을 따로 비교합니다. **7일 합계 평가는 동일한 매장·상품군·기준일의 7개 정답과 7개 예측을 각각 합한 뒤** 비교합니다. 합계 WAPE가 작아도 월요일의 과대예측과 화요일의 과소예측이 상쇄되었을 수 있으므로, 일별·horizon별 오류와 Bias를 같이 봐야 합니다. 현재 두 입력 체계는 달라 결과를 모델 구조만의 승패로 단정하지 않습니다.

현재 Test 주간은 과거 실험에서 이미 여러 차례 살펴보았습니다. 최종 모델 선정에 다시 쓰면 Test를 통한 추가 조정이 되므로 이 표는 **회고적 결과**로 설명합니다. [06 오류 분석 노트북](../../notebooks/06_error_analysis.ipynb)의 매장·상품군 검토를 보강하고, 수요 군집별 오류와 운영 시각화는 후속 분석으로 남깁니다.

## 이전 실험과 분리할 수치

최근 365개 예측 기준일을 사용한 **과거 LightGBM L1 실험**은 최근 28개 기준일에서 WAPE 13.26%, MAE 62.84, RMSLE 0.3943이었습니다. 같은 실험의 전주 동일 요일 Baseline WAPE는 17.96%, 최근 4주 동일 요일 평균은 14.76%였습니다. 이는 현재 전체 이력 L2·7일 Valid/7일 Test 실험과 **학습 기간, 목적함수, 평가 분할이 달라** 우열 비교에 넣지 않습니다. 기존 설정과 산출물의 맥락을 보존하기 위한 기록입니다.

## 의사결정 해석의 경계

과소예측은 품절 위험을, 과대예측은 재고 부담을 검토할 신호가 될 수 있지만, 이 데이터만으로 실제 품절·폐기·비용을 측정하지는 못합니다. 다음 단계에서는 수요 규모와 변동성별 오류, 점포별 Bias, 7일 합계의 큰 실패 사례를 함께 보여줍니다. 개별 상품 발주 추천은 SKU별 판매 예측을 따로 검증하고 재고·납기 정보를 확보한 뒤에야 계산할 수 있습니다.
